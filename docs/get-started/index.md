# Get started

New to `presto`? Three pages will get you from a blank machine to a bespoke force field.

## Recommended path

1. **[Installation](installation.md)** — install `pixi`, clone the repo, and verify the environment. (`presto` is also on `conda-forge` as `presto-fit`, but comes without the MLP dependencies by default.)
2. **[Quickstart](quickstart.md)** — a single command that produces a bespoke force field for one SMILES.
3. **[Walk-through (CLI)](../examples/basic-walk-through-cli.ipynb)** — the same fit, but stepping through the YAML and the outputs.

## Already installed?

Jump straight to **[Quickstart](quickstart.md)**.

## Prefer Python over the CLI?

After Installation, see the **[Walk-through (Python API)](../examples/basic-walk-through-python-api.ipynb)** notebook, then **[Run from Python](../how-to/run-from-python.md)**.
