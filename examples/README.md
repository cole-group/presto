# Examples

Runnable notebooks demonstrating `presto`:

- [Basic walk-through (CLI)](basic-walk-through-cli.ipynb) — using `presto train-from-yaml` end-to-end.
- [Basic walk-through (Python API)](basic-walk-through-python-api.ipynb) — building `WorkflowSettings` programmatically, including a demo of injecting an ASE calculator.

Both are surfaced from the **Get started** section of the [documentation site](https://cole-group.github.io/presto/latest/).
